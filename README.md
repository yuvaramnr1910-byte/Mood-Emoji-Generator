# Mood-Emoji-Generator 😊

A simple Python project that generates emojis and positive messages based on your current mood.

## Supported Moods
* happy 😊
* sad 😢
* angry 😡
* love ❤️
* excited 🤩
* tired 😴
* cool 😎

## How to Run
1. Make sure Python is installed on your computer.
2. Download mood.py from this repository.
3. Open your terminal or command prompt and run:
   bash
   python mood.py
